# 文件与本地数据分析：实现范围和验证边界

## 1.3.0 补充

- 材料包按用户清单检查缺项、文件扩展名与大小；不判断文件内容或机构规则。每包最多 20 项，最多 30 包与 30 个个人模板。模板不含文件绑定。
- 工作区新增多选和角色筛选，批量追加标签、移入集合、回收与恢复。业务引用文件仍受删除保护，包括材料包绑定；批量整理逐项报告失败。
- 批量导出、系统分享与 ZIP 每次最多 100 个文件，总大小最多 500 MB。交付名称安全化、重名编号；分享复制到临时缓存后传出，避免接收方取得内部路径文件名。分享缓存供异步读取，可在设置中主动清理。
- 全局文件搜索与工作区复用名称、标签、集合的元数据查询；外部分享导入后由用户选择处理目的。
- 完整备份包含材料包与模板；恢复时重新映射材料文件路径。单个备份实体允许超过普通文件导入的 100 MB，上限受完整备份总文件实体 1 GB 约束，以便恢复工作区生成的大 ZIP。
- 备份本机生成和系统导出分别持久化；取消导出不标记成功，可继续导出。旧版备份时间仅显示为生成记录，导出状态未知。
- 新增测试：`test-material-packs.cjs`、`test-batch-files.cjs`、`test-search.cjs`、`test-release13.cjs`。原生系统分享、picker 与 ZIP 编码仍需要目标设备验证。

## 已实现

- 系统 DocumentViewPicker 主动授权选择文件，复制到 `filesDir/workspace`，保留原文件只读；真实元数据登记至统一 RDB 文档索引。
- 工作区与每个处理结果可预览、调用系统保存选择器导出、调用 Share Kit 分享，并直接将同一个副本送入后续工具。
- PDF Kit 真实结构合并、按页拆分、指定页面提取、逐页 PNG 输出、批量图片生成 A4 PDF。保存后重新载入并校验输出页数。
- 图片 PNG / JPEG / WebP 批量编码，可设置质量和输出宽度，保持纵横比；HEIC 输入由设备 Image Kit 实际解码能力决定。
- UTF-8 CSV ↔ JSON；TXT / Markdown 文件转换。CSV 支持 BOM、引号内逗号和换行、双引号转义及 CRLF。
- CSV 本地分析：文件导入或文本输入、分页表格预览、按列排序和包含筛选、空值检查、整行去重、空白行移除、恢复原始数据、计数/求和/均值/最值、按列分组计数和数值求和、条形/柱状/折线/饼图、清洗表与分组汇总导出，以及最多 10 个本地分析项目。
- PDF 和图片批量处理在 TaskPool 中执行，显示实际批次/页进度，支持取消与重新执行。取消在当前原生操作结束后的检查点生效，失败会清理本次生成的结果。

## 明确限制

- **PDF 合并不会以页面截图代替结构操作。** 安装 SDK 的 `insertPageFromDocument` 明确不复制批注；因此含链接或批注的源 PDF 会被检测并拒绝合并，避免静默损失内容。合并输出默认未加密，不提供输出密码设置。
- PDF 拆分、提取通过加载原文档并删除其余页面另存实现；提取结果保持源页面顺序，同一页不会重复输出。跨页链接、加密文件和复杂表单仍需要支持 PDF Kit 的真机进一步验证。
- PDF 运行依赖 `SystemCapability.OfficeService.PDFService.Core`。界面会检查设备支持并报告不支持；编译成功不能代替真机 PDF 渲染及系统选择器的验证。
- 输入每批最多 20 个文件，单文件最多 100 MB；图片最多 4,000 万像素；图片尺寸调整仅缩小，宽度上限 8192 px。PNG 为无损编码，质量设置主要适用于 JPEG / WebP；JPEG 不保留透明通道。
- 图片转 PDF 每图一页、A4 等比居中，内部先生成 JPEG；不会保留透明通道、HDR 或全部源图元数据。当前没有自定义纸型和图像方向编辑。
- 文本导入最多 4 MB；CSV 最多 20,000 行和 100 列。解析在后台进行，预览每页 12 行。当前为有界内存数据集，未实现任意大小文件的流式分析。
- CSV→JSON 将全部单元格保留为字符串，以保留前导零和原始文本。JSON→CSV 只接受扁平对象数组；null 和缺失值变为空单元格，数字/布尔值转为文本；嵌套对象和数组明确报错。CSV 空表头和重复表头会生成非空且唯一字段名。
- 混合类型列按文本排序；全数值列按数值排序并将空值置后。空值和非数值不参与数值统计。
- 图表展示前 8 个分组，完整分组可导出；饼图仅支持非负且总和大于零的度量。图表可以导出 1200 × 900 PNG；不提供交叉统计、散点图或直方图。
- TXT / Markdown 转换保留文本内容并统一换行，不重建富文本排版。XLSX、PDF 图像压缩和页面整理已在 1.2.0 新增；Office 转 PDF、XML 映射和水印尚未提供。
- 旧版 JSON 元数据备份不包含原文件。1.2.0 完整备份包含文件实体和资料校验，换机时重新关联附件；不完整或损坏的包会停止恢复。路径限定为工作区直接子文件，拒绝目录和符号链接，避免备份路径越界。
- 工作区删除前检查已保存的物品和表单回答引用，关联文件会被阻止删除；请先在相应记录中解除附件关联。历史记录只保留操作说明，文件删除后历史不能恢复该文件。

## 统一任务生命周期

文件处理使用 `TaskManager` 将最近 100 条任务元数据保存到 RDB 的 `tasks` 文档：`pending → running → completed / failed / cancelled`。TaskPool 实际进度按 500 ms 节流写入；迟到进度不会覆盖终态。完成状态在实际结果登记到工作区后保存。

应用重新启动时，未完成的 `pending` / `running` 任务标记为失败，并说明可重试；不会假装仍在后台执行。记录仅包含工具、状态、进度、文件路径和错误说明，不持久化 PDF 密码、转换参数或输入正文。重试时重新确认参数；文本预览转换没有持久化输入路径，需重新输入内容。任务记录属于瞬态处理历史，不纳入元数据备份。

生命周期测试：

```sh
/Applications/DevEco-Studio.app/Contents/tools/node/bin/node scripts/test-task-manager.cjs
```

覆盖状态迁移、进度节流、取消终态、启动恢复、并发写入和 100 条上限、损坏数据过滤、存储读取失败保留原记录。

## 1.2.0 补充

XLSX 支持最多 30 张工作表，读取共享字符串、内联文本、数值、日期、布尔及缓存公式值，不运行公式。原文件上限 20 MB，ZIP 内部单项上限 12 MB、总声明展开大小上限 32 MB。解压使用固定输出缓冲和 CRC 校验，不向磁盘展开包路径。

PDF 图像压缩和可视化整理最多 200 页；图像压缩为静态副本，不能保留可选文字、链接或交互表单。保留原件，未达目标时提示，结果不比原件更小时不发布。页面整理使用原文档结构操作。

完整验收边界见 `docs/validation/NEXT_VERSION.md`。
