集萤 1.3.0｜材料备齐，一次交付

• 新增材料包：按清单逐项关联文件，检查缺项、格式和大小；支持从工作区选择或导入新材料。
• 清单要求可保存为个人模板，下次创建材料包时复用，不带入上次关联的文件。
• 材料符合要求后，可一次导出、系统分享、打包 ZIP，或将图片和 PDF 合并整理为一份 PDF。交付副本使用清单项名称，原件保留。
• 文件工作区新增多选、全选当前筛选结果、批量标签、归入集合、移入回收站及恢复；已关联资料的文件继续受删除保护。
• 支持多文件导出与分享、ZIP 打包，以及原件／中间结果／最终成果筛选。
• 全局文件搜索支持标签与集合；工具搜索支持“缩小照片”“识字”等日常说法。
• 从其他应用分享文件到集萤后，可先选择压缩、识字、整理等处理目的。
• 完整备份区分“本机已生成”和“已成功导出”；取消导出后可继续，材料包与清单模板可随完整备份恢复。

## 与知萤、词萤联动

本次更新增加与词萤和知萤的联动，并修复部分已知问题。

1. **图片 OCR 与笔记、伴读联动**：识别结果可发送至知萤的「集萤」工作区，提取英文核心词汇并生成双链与查词入口；英文书页或讲义可送入词萤进行全文点词伴读或提取生词。
2. **数据分析报告**：CSV / Excel 分析可生成包含数据集概览、数值统计、分组透视与样本预览的结构化 Markdown 报告，归档至知萤的「数据报告」。
3. **物品与借还档案**：资产信息、借还记录和附件清单可整理至知萤的「物品档案」，并支持从集萤打开关联笔记、从笔记回跳集萤。
4. **表单归档**：表单汇总或单份答卷可整理至知萤的「表单归档」，并通过链接回到集萤工具台。

联动需要词萤 1.3.0 及以上、知萤 1.2.0 及以上；系统无法直接打开知萤时，可通过分享面板选择知萤。

材料包最多保存 30 个，每包最多 20 项；个人清单模板最多 30 个。格式与大小要求由用户按接收方要求填写，检查不判断材料内容是否有效。批量文件操作每次最多 100 个，批量交付总大小上限 500 MB。完整备份文件实体总上限仍为 1 GB。

批量 OCR 与正文检索属于后续 1.3.1 范围，本版保留单图文字识别。
